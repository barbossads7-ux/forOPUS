# СТАРТ — как открыть новый проект sitecraft-mcp

Эта папка — приложение к присланному набору владельца (`skimreel_new`: `CLAUDE.md`, `SPEC.md`, `RESEARCH.md`,
`DECISIONS.md`, `START_PROMPT.md`, zip). Тот набор лежит как есть и главный. Здесь только то, что принесено из
старого проекта Skimreel и чего в наборе нет. Ничего из набора я не менял и не переписывал.

## Где что лежит (папка проекта — `~/Documents/SkimReel_proj/`)

Проект начинается здесь, в `SkimReel_proj`. Всё остальное — данные для него.

```
SkimReel_proj/
├── CLAUDE.md          ← из набора владельца (корень проекта!)
├── DECISIONS.md       ← из набора владельца
├── START_PROMPT.md    ← из набора владельца: его вставить первым сообщением
├── docs/
│   ├── SPEC.md        ← из набора владельца
│   └── RESEARCH.md    ← из набора владельца
└── переезд/           ← эта папка (уже лежит внутри)
```

Набор владельца (`Downloads/skimreel_new`) копируется как есть, без правок: лучше распаковать zip
`sitecraft-mcp-handoff.zip` в корень `SkimReel_proj` — структура с `docs/` получится сама.

## Что в этой папке и зачем

| Файл | Зачем | Когда читать |
|---|---|---|
| `СТАРТ.md` | Этот файл: что куда и в каком порядке | Первым |
| `уроки-коннектор-claude.md` | Проверенные вживую факты про OAuth и иконку коннектора в claude.ai, ловушки в описаниях инструментов. Закрывает открытую проблему «как claude.ai работает с авторизацией» (частично: OAuth проверен, ключи нет) | На этапе 0 (подключение) и 5 (продажа) |
| `правила-владельца.md` | Правила владельца, которых нет или которые расходятся с присланным `CLAUDE.md` (выкладка по «да», платные замеры по «да», размер `DECISIONS.md`) | Сразу после `CLAUDE.md` |
| `unslop/` | Навык (CC BY 4.0, автор Damir Sokolovsky): аудит ИИ-признаков в интерфейсе, список признаков `references/signs.md`. Не часть продукта. Это справочник к `slop_check`: сверить правила, не копировать | Перед этапом 1; если нужен как навык — положить в `.claude/skills/` проекта |

## Что нового проекта НЕ касается (чтобы не тащить)

Это Skimreel: Telegram-бот, Mini App, SQLite, звёзды, yt-dlp, Gemini и OpenRouter, VPS 46.226.167.43. Продукт
sitecraft-mcp — без хранения данных и без внешних платных API. Старый проект работает отдельно, его не менять.
